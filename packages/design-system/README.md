# Design system — tokens técnicos

`tokens.json` é a fonte técnica. `tokens.css` e `tokens.mjs` são gerados por `npm run tokens:gerar`; `npm run tokens:verificar` detecta divergências. Para regras de composição, contraste, logo e fotografia, leia `docs/design-system.md` e a Revista de Marca.

As famílias tipográficas ainda são **provisórias**; as fontes não estão embutidas. O app futuro deve carregar fontes licenciadas e aprovadas antes de aplicá-las. A escala da revista é referência desktop/editorial, sem breakpoints móveis definidos. Cores de produto precisam de amostra física de filamento antes de serem consideradas finais.
