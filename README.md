# Per Parte

Luminárias impressas em 3D, montadas por partes pelo próprio cliente e fabricadas sob demanda — com marketplace de criadores e royalty por parte.

Este repositório reúne os documentos de produto e o protótipo do configurador. Comece por `CLAUDE.md` (contexto para o Claude Code) e `docs/`. Para ver o protótipo, abra `prototipo/configurador.html` no navegador.
